HOW TO USE

1. Put it on the vocal track
The vocal goes through untouched.
2. Get the slice
Drop a one-shot or a vocal slice, or press CAPTURE with the song playing: it records the next beat of the track.
3. Shape the build
LENGTH in bars, ROLL for how it speeds up (1/4 → 1/8 → 1/16 → 1/32). GATE START and END set how much of the slice plays on each hit. PITCH and FILTER rise to the drop. REVERSE turns the last hit around.
4. Listen and drag
PREVIEW plays it on the next bar. Drag the bar at the bottom into Ableton and put the clip right before the drop.
